## 📊 Dashboard Features

- Restaurant ratings analysis
- Cost vs rating insights
- Restaurant type analysis
- Table booking impact on rating
- Online order impact on rating
- Top premium restaurants analysis

---

## 📈 Business Insights

1. Restaurants that allow **table booking** tend to have higher ratings.
2. Premium restaurants often receive **better customer ratings**.
3. Certain restaurant types perform better in terms of **average ratings**.
4. Cost and rating show interesting **customer perception trends**.

## ▶️ How to Run the Project

Install dependencies:

pip install -r requirements.txt

Run the Streamlit dashboard:

streamlit run app.py

Then open in browser:

http://localhost:8501
