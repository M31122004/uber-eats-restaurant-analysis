# 🍔 Uber Eats Restaurant Analysis Dashboard

An interactive **Data Analysis Dashboard** built using **Python, MySQL, Pandas, Plotly, and Streamlit** to analyze restaurant data from Uber Eats.

This project explores restaurant ratings, locations, cuisines, and cost insights using data visualization.

---

## 📊 Project Overview

This project performs end-to-end data analysis:

1. Data Cleaning using **Pandas**
2. Data Storage using **MySQL**
3. Data Querying using **SQL**
4. Data Visualization using **Plotly**
5. Interactive Dashboard using **Streamlit**
